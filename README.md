# Mosaème — versions publiées

Ce dépôt ne contient que les installateurs Windows de Mosaème, signés, et le fichier `latest.json` lu par la mise à jour intégrée de l'application.

- **Installer Mosaème** : ouvrez la dernière version dans « Releases », puis téléchargez le fichier se terminant par `-setup.exe`.
- **Mettre à jour** : rien à faire ici. Mosaème propose lui-même les nouvelles versions (Paramètres › Mise à jour de l'application).

Chaque installateur est signé. Mosaème refuse d'installer un paquet dont la signature ne correspond pas à sa clé publique.
